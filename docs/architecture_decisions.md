# Architecture Decisions

This repository uses lightweight architecture decision records (ADRs) to document why certain workflow patterns exist.

| ADR | Decision |
|---|---|
| [0001](adr/0001-file-based-workflow-contracts.md) | Use file-based workflow contracts |
| [0002](adr/0002-approval-gated-identity-changes.md) | Gate high-impact identity changes with approval records |
| [0003](adr/0003-sanitized-sample-data-demos.md) | Prefer sanitized sample data for demo workflows |

ADRs are intentionally short. They capture durable decisions that shape several scripts or documents, while implementation details stay in the task-specific guides.
